# 🎮 Rock Paper Scissors

A simple, interactive Rock Paper Scissors game built using the C programming language.

## 📌 About the Project

This project lets a player compete against the computer in the classic Rock Paper Scissors game. The computer randomly selects a move, and the program determines the winner of each round.

## ✨ Features

* 🎯 Player vs Computer gameplay
* 🎲 Random computer moves
* 🏆 Score tracking
* 📊 Match statistics
* 🔄 Multiple rounds
* ✅ Input validation
* 🥇 Final match results

## 🛠️ Technologies Used

* C Programming Language
* GCC Compiler
* Visual Studio Code

## ▶️ How to Run

### Requirements

Install a C compiler such as GCC.

### Steps

1. Clone this repository.

2. Open the project folder in your terminal.

3. Compile the program:

   ```bash
   gcc game.c -o game.exe
   ```

4. Run the game on Windows:

   ```powershell
   .\game.exe
   ```

## 🎮 How to Play

| Input | Action   |
| ----- | -------- |
| 1     | Rock     |
| 2     | Paper    |
| 3     | Scissors |
| 0     | Quit     |

**Rules:**

* Rock beats Scissors.
* Scissors beats Paper.
* Paper beats Rock.
* Identical moves result in a draw.
